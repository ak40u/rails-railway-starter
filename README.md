# Rails starter for Railway

Rails 8.1 on Ruby 3.4, in the production container Rails generates for itself.

## Why this exists

The Rails template on Railway deploys a starter pinned to Rails 7.0.3 and Ruby
3.1.2 — both from 2022. About one deployment in six fails.

It also deploys Redis from `bitnami/redis` **with no tag**. Bitnami restricted its
public catalogue in 2025: the public repository now carries digests and metadata
but no version tags, so a plain `bitnami/redis` reference is a pull waiting to
fail. This starter does not ship Redis at all — add it when you actually need
Solid Queue or Action Cable at scale, and use the official `redis` image.

## What's in here

A `rails new` scaffold on current Rails, plus four changes:

| Change | Why |
|--------|-----|
| `HTTP_PORT` bridged from `PORT` | Thruster defaults to 80; the platform assigns the port |
| `railway.json` | Health check on `/up`, restart on failure |
| Encrypted credentials removed | The master key is gitignored, so a template cannot rely on it — `SECRET_KEY_BASE` is used instead |
| A root route | A fresh Rails app has no `root`, so a deployed template would greet you with a 404 |

Everything else is Rails' own production `Dockerfile`: multi-stage, non-root user,
jemalloc, bootsnap precompiled, assets built at image time.

## Health check

`/up` is Rails' built-in health endpoint — it returns 200 only if the app boots
without raising, so a red check means the application genuinely cannot start.

Migrations run through Rails' own `bin/docker-entrypoint`, which calls
`db:prepare` before the server starts: it creates the database on first deploy and
migrates on subsequent ones.

## Run locally

```bash
bundle install
bin/rails db:prepare
bin/rails server
```

## Configuration

| Variable | Required | Purpose |
|----------|----------|---------|
| `SECRET_KEY_BASE` | yes | Signs sessions and cookies — generated by the template |
| `DATABASE_URL` | yes | Postgres connection, wired to the bundled database |
| `RAILS_ENV` | no | `production` |
| `PORT` | no | Defaults to 8080 |
